# Hafalan Al-Qur'an

Aplikasi Android pribadi untuk menghafal Al-Qur'an, dimulai dari Juz 30. Berjalan penuh tanpa internet; rekaman murojaah dan data hafalan tersimpan di HP.

## Status

Tahap dokumen keputusan — kode aplikasi belum ditulis. Lihat [docs/keputusan.md](docs/keputusan.md) untuk keputusan terkunci, rencana fase, dan pertanyaan terbuka.

## Rencana teknis (usulan)

- React + Vite + TypeScript, dibungkus Capacitor menjadi APK
- Data di IndexedDB (Dexie), rekaman per ayat di memori HP
- APK dibangun otomatis oleh GitHub Actions

## Atribusi data

Teks Al-Qur'an dari [Tanzil Project](https://tanzil.net) (CC BY 3.0), dipakai apa adanya tanpa perubahan.
